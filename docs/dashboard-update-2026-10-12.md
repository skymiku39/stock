# Dashboard 更新：2026-10-12

介面版本：`workspace-2026.10.12`。重新整理既有的 Dashboard 網址即可載入程式改動。

## 三個可直接核對的改變

1. **介面與導覽**：首頁改成研究工作台，顯示股票入口、追蹤清單、最近任務和更新摘要。側欄只展開常用入口，其餘功能依分組收合，也能搜尋頁面名稱。服務啟停與診斷資訊移至收合區。使用一致的淺色、青綠主色、留白與卡片版面。
2. **工作進度**：支援背景執行的操作送出後會立即建立任務。所有頁面的側欄都可看見進行中任務，完成時提示；任務中心提供狀態、耗時、階段、失敗原因、原設定、結果下載與手動重試。重複送出相同的進行中工作會共用同一任務。
3. **改動說明**：首頁與側欄加入「本次更新」，說明變更位置與適用範圍，不再只提供難以理解的 build 字串。

## 直接試用

1. 首頁輸入代號，例如 `2330`，按「開啟個股分析」。
2. 個股頁展開「資料與分析選項」，預設會在按「開始分析」後更新日 K 與收盤價；若只要使用本地資料，先關閉「抓日K + 指標」。單純輸入代號、切頁或開啟結果不會重新送出分析。
3. 切換至其他頁面。從側欄查看任務狀態，再到「任務中心」按「查看結果」。
4. 需要更新其他來源或使用 LLM 時，明確勾選對應選項再送出。日 K 與收盤價不等於即時報價；缺資料、來源失敗與部分完成會保留提示。

## 背景執行範圍

- 個股深入分析、Watchlist 評分。
- LLM 自動研究，包含 MOPS、新聞、網頁搜尋與研究整理。
- 逐字稿分析、言行反查。
- 持股資料整理、LLM 投組分析。
- 自動化研究管線、今日當沖報告、明日關注報告、手動即時推演。
- 跨市場資料更新、LLM 跨市場簡報、盤中強弱排行搜尋。

券商連線、雲端同步、ETF 抓取、個別來源維護與即時行情表刷新仍依原流程執行；未接入任務中心的操作不要視為可離頁的背景任務。

切頁、重新整理或關閉瀏覽器不會停止已送出的背景任務。電腦和 Dashboard 服務須維持運作；服務停止後，執行中任務會在心跳逾時（30 秒）後標為「已中斷」，不會自動重跑可能已消耗額度的 LLM。排隊任務在服務恢復後繼續；已完成結果保留於本機。只能取消尚未開始的排隊任務。

## 實作與驗證方式

任務服務與 UI 分離；工作執行緒不使用 Streamlit API 或 session state。任務與 JSON 結果存在專案的 `data/dashboard_tasks.sqlite`，以交易避免重複送出並維持同一專案一次一項工作。UI 約每 2 秒更新任務狀態；未知完成比例時只呈現階段與實際耗時。

自動測試涵蓋切頁後繼續、重新建立瀏覽器工作階段取回結果、重複送出、排隊取消、部分失敗、中斷辨識及頁面載入不自動連外。測試使用隔離資料與假的來源，並不代表真實券商、LLM、外部來源或視覺排版已完成驗收。
