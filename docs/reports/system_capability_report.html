3.2 量化評分（scoring）

四時間框架：day_trade／short_term／mid_term／long_term。 九因子：llm_sentiment、logic、etf_consensus、chips、technical、fundamental、distribution、us_market、risk。 缺資料因子會從加權剔除（不以中性 50 稀釋）。

分數門檻動作
≥ 78STRONG_BUY
≥ 62BUY
≥ 45HOLD
≥ 30REDUCE
< 30SELL

覆蓋率 < 50% 強制 HOLD；< 80% 時 STRONG_BUY 降為 BUY。進場／停損／停利為建議價，非 bot 環境參數。

3.3 技術／基本面／籌碼

  • technicals：日 K、MA／MACD／RSI／KD／布林、technical_score、16 種單根 K 型態
  • fundamentals：月營收 YoY／MoM、PER／PBR／殖利率、股利、季報 EPS／三率
  • chips：三大法人／融資券／借券／鉅額 N 日彙總
  • chip_distribution：TDCC 大戶 vs 散戶結構分數
  • etf_consensus：主動 ETF 共識持有、新建倉、加碼訊號

3.4 LLM 與 Prompt

主路徑 research_ticker 已含 presentation_block（法說原文）與 quant_block（基本面／籌碼／ETF）。 言行反查走 logic_check。Ask 另用 query_plan／ask_answer。

3.5 敘事管線

  • intraday：theme_radar → 候選池 → day_trade 評分 → intraday_brief
  • next_day：催化＋強度 → next_day_radar → 合成分數 → next_day_brief
  • data_pipeline：ETF → 共識 → 籌碼 → 法說 LLM → daily_brief／us_market_brief
  • portfolio_analysis：持股證據包 → LLM 操作建議（不下單）
  • smile_curve*：階梯加碼策略、選股、回測／稽核

3.6 Ask／記憶

流程：QueryPlan → 本地 EvidencePack → ask_answer → evidence_id 驗證 → 通過才回答；失敗則「我不確定」。 僅寫入短期記憶；長期需品質通過或管理者核准。Ask 不會在問答當下打外網 API。

4.3 Bot 進出場判斷

flowchart TB
  MAIN[main.py] --> ARCH{{day_trading archived?}}
  ARCH -->|trade 且未解凍| ERR[拒絕啟動]
  ARCH -->|ok| ST{{STRATEGY_TYPE}}
  ST -->|configurable| CS[ConfigurableStrategy]
  ST -->|etf_follow| EF[EtfFollowStrategy]
  CS --> ER[entry_rules 漲幅區間]
  ER --> LG[LlmGate.allow_entry]
  LG --> RG[RiskGuard]
  EF --> SIG[ETF follow 訊號]
  SIG --> LG2[LlmGate.allow_entry 可選]
  LG2 --> RG[RiskGuard]
  RG --> ORD[下單或虛擬 would-buy]
  CS --> EX[出場: 停損/移動停利/目標/收盤]
  EX --> LGX[LlmGate.allow_exit 可選]

重要差異：ConfigurableStrategy 進場必經 LlmGate； EtfFollowStrategy 預設略過 LLM 進場閘（共識訊號為主），設 ETF_FOLLOW_LLM_GATE=true 可對齊。

層級判斷點結果
產品安全day_trading_archived 且 RUN_MODE=trade拒絕實單（需 DAY_TRADING_UNFREEZE）
模式trade / watch / report實單 vs 虛擬訊號
進場價格in_entry_range / 回落買回是否觸發進場嘗試
LLM 進場sentiment、day_trade 分數門檻允許或封鎖（configurable；EtfFollow 可選）
風控資金／張數／黑名單／日損／冷卻／漲幅上限調整數量或封鎖
出場停損、移動停利、目標賣、收盤清倉觸發賣出
LLM 出場閘llm_sell_gate_enabled可能擋賣（停損／收盤可 bypass）
評分四框架 scorecard儀表板與當沖排序；非直接下單
Askevidence_ids 驗證失敗棄權「我不確定」
