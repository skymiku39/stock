# 進場時機研究（2026-11-17）

問題：微笑方案與波段原型的失敗分析顯示進場沒有優勢（波段原型甚至比隨機差）。這份研究只看進場：哪些收盤時可觀察的條件，之後的超額報酬比任意一天進場好。

## 結論

1. **「哪一天進場」的條件都沒有優勢。** 逢低（距高點跌 10%／15%、RSI 超賣、全市場恐慌）、突破（20／60 日、帶量、波動收斂後）、上升趨勢中回檔，在兩段資料都和任意一天差不多，或更差。加上大盤濾網（60／200 日均線）也沒有改善。兩個策略的進場邏輯（微笑＝逢低、波段＝突破）都在這一類。
2. **有差的是「買哪一檔」**：相對強度（過去 60 日漲幅在名單內的排名）與月營收年增率。
   - 相對強度前 20%：比任意一天好 +0.80 → +1.58 個百分點（參數決定段 → 驗證段，20 日）。
   - 營收年增 > 20%：+0.66 → +2.08。
   - 反面兩段都明顯較差：相對強度後 20%（−0.56 → −0.40）、營收年增 < −10%（−1.01 → −0.39）。
3. **唯一通過事先標準的是 C2「相對強度前 40% 且營收年增 > 0%」**：參數決定段 20 日超額 +0.61%（比任意一天好 +0.96）、t 2.1、4 年中 3 年為正；驗證段 +1.68%（好 +2.10）、t 2.4、3 年都為正。40 日更明顯（+1.57% → +4.27%）。
4. 優勢在 20～40 日才出現，5 日內沒有。這類條件是挑股票，不是抓買點，適合持有數週到三個月，和使用者定的持有期間相符。

## 第三輪：月線、年線與營收（使用者建議）

年線需要 240 個交易日，訊號 2021 年起才有，所以用同期間的 C2（M9）對照。

- 參數決定段（2021～2023）：均線條件都沒有優勢。站上月線與年線（M1）和任意一天差不多（−0.03 個百分點），多頭排列（M3）也是 0。
- 加在 C2 上沒有幫助：C2 同期間 +0.53%，加年線 +0.50%（M7），加月線與年線 +0.38%（M8）。
- 驗證段均線條件都轉正（M1 +0.88、M2 +1.11），但那段是大多頭，多數股票都在均線上，看到的主要是大盤方向。跌破年線（M4）在驗證段明顯較差（−1.11），參數決定段則沒有（+0.08），不能據此當排除條件。
- 決定（依參數決定段）：C2 不加均線條件。

## 可信度與限制

- 共測了 40 個條件，事先標準下純靠運氣通過一個的機率不低。C2 是看過第一輪結果後加入的組合（驗證段的單因子結果也已看過），所以驗證段對 C2 只算弱證據。**真正的檢驗是前瞻資料（2026-11 之後）。**
- 「任意一天」本身是 −0.35%，因為等權指數每天再平衡、進場又用次日開盤；所以比較時看「減任意一天」那欄。
- 名單是 60 檔成交量最大的股票（排除 2330），有存活者偏誤：現在成交量大的股票，過去多半表現好。相對強度的優勢可能部分來自這裡。
- 只看進場後固定天數，沒有出場規則、費稅與滑價；事件後 20 日內同一檔不重複計入；t 值以月為群組。
- 月營收在次月 11 日才視為已知；價格經除權息還原。
- 籌碼資料只從 2026-09 開始，無法回測，沒有納入。

## 建議的下一步（尚未做）

把 C2 當選股條件，搭配既有出場規則，只用參數決定段設計，凍結後加進前瞻追蹤，和兩個舊策略並列觀察；不再用驗證段調整。
